# Security

## Supported versions

Only the latest release and `main` get fixes.

## Reporting a vulnerability

Report it privately through GitHub's form:
https://github.com/inceptyon-labs/athena/security/advisories/new

Please don't open a public issue. Include what you found, how to reproduce it, and what an attacker could do with it
(read someone's API key, use Describe It without Plex access, and so on).

## What to expect

A reply within a week. Once the fix is out, the advisory is published with credit, unless you'd rather stay unnamed.
